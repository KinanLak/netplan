# Architecture

- **[Current](current.md)** — the code as it stands: map editor, map
  operations, accounts, sites with their inventory and collection, the Docker
  deployment, and the development and delivery tooling.
- **[Target](target.md)** — where the remaining lots of the rebuild take it:
  the map's ports and statuses, the experience, history and operations.

Decisions behind both pages are in [`docs/adr/`](../adr/index.md). When a lot
lands, it moves what it built from Target to Current.
