# Architecture

- **[Current](current.md)** — the code as it stands: map editor, map
  operations, accounts, sites with their inventory and collection, history
  and the push to NetBox, the Docker deployment, and the development and
  delivery tooling.
- **[Target](target.md)** — where the next lots take it. The rebuild is
  complete and none is planned.

Decisions behind both pages are in [`docs/adr/`](../adr/index.md). When a lot
lands, it moves what it built from Target to Current.
